## 鼠标手势导航

怀旧学生时代使用过的Pointix公司出品的一款叫**Pointix PopMouse**的软件，那时鼠标底部还是个滚球。
在 Windows 资源管理器中可通过鼠标画圈圈进行导航

- **顺时针** ： 后退
- **逆时针** ： 前进

无需按下鼠标键；仅**文件列表区域**生效


## 标题栏按钮

- **置顶按钮**  ：单击置顶
- **窗口切换按钮** ：显示窗口切换器

## 快捷键

- **CTRL+TAB** ：显示窗口切换器, 按住CTRL不放，继续按TAB，将窗口前置


## 其他

- **鼠标里程仪** ：记录每天用鼠标移动距离换算的公里数
