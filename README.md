# Explorer 手势导航

在 Windows 资源管理器的**文件列表区域**用鼠标画圈导航：

- **顺时针** → 后退
- **逆时针** → 前进

手势触发且**确实发生导航**时（未到顶），才会在资源管理器窗口的**右下角弹出一个半透明的手势图标**
（约 56×56 像素，不透明度 0.72），约 1.3 秒后淡出消失；同时播放提示音。

提示音默认使用 **Windows 系统自带的「导航」声音方案**（与资源管理器自身的导航音一致）。
如果想换回程序内置的自定义提示音，可在托盘菜单取消勾选「使用系统导航音效」。

## 为什么用 C#

需求全部落在 Windows 原生 API 上（低级鼠标钩子、窗口类名探测、`WM_APPCOMMAND` 导航、winmm 播声音）。
C# 用 P/Invoke + WinForms 托盘程序即可完成，无需第三方依赖；Rust 需要 `windows` crate、COM 绑定和额外的音频依赖，代码量与调试成本都更高。

## 工作原理

1. `MouseHook`：`SetWindowsHookEx(WH_MOUSE_LL)` 全局采集鼠标移动，钩子运行在独立的 STA 消息循环线程上。
2. `ExplorerListHitTester`：对每个鼠标位置做 `WindowFromPoint` + `GetAncestor(GA_ROOT)`，
   要求顶层窗口类名为 `CabinetWClass` / `ExplorerWClass`，且光标所在控件位于 `SHELLDLL_DefView` 子树内
   （文件列表宿主，含列表本体、列头、滚动条）。导航窗格、地址栏、状态栏、预览窗格都不在该子树内。
   判定结果按控件句柄缓存，但**缓存带 500ms 有效期且校验句柄有效性**：窗口句柄会被系统回收复用，
   资源管理器重建子窗口时同一个句柄数值可能代表完全不同的控件，永久缓存会返回错误结果。
3. `CircleGestureTracker`：累积轨迹点，逐段计算有符号转角（叉积 + `atan2`）求和，顺时针为正。
   仅靠转角会把"横向来回摆动"误判成圈（来回一趟就是一个极扁的椭圆，同样能凑满 360°），
   因此再叠加形状校验：直径区间、`扁度`（包围盒短边/长边）、`起伏`（轨迹点到中心距离的变异系数）。
   鼠标静止超过 260ms、按下鼠标键、或离开列表区超过宽限期都会重置轨迹。
4. `NavigationInvoker` + `NavigationGate`：投递 `WM_APPCOMMAND`（与鼠标侧键同一条路径，不要求窗口为前台），
   并用闸门保证同一时刻只有一个动作在执行。
5. `GestureOverlay`：无边框分层窗体，位于目标窗口客户区右下角；带 `WS_EX_NOACTIVATE`（不抢焦点）、
   `WS_EX_TRANSPARENT`（鼠标可穿透）、`WS_EX_TOOLWINDOW`（不出现在 Alt+Tab）。

## 连续手势：不排队，只忽略

**识别与执行解耦**：

| 阶段 | 行为 |
|---|---|
| 手势识别 | 始终进行，闸门忙碌期间不清空轨迹 |
| 动作执行 | 闸门空闲才执行；忙碌时识别到的手势直接丢弃，不排队、不补执行、不发声 |

判定"上一个动作执行完"用组合信号：最短占用 120ms → 轮询窗口标题（目录名）→ **目录一变立即释放** → 最长 300ms 兜底。
闸门只用于防抖（阻止同一次画圈被重复执行），不再要求用户停顿：连续画两个圈会执行两次。

## 稳定性相关设计

- **识别与反馈解耦（到顶不响）**：识别到手势只投递导航命令，并不立即发声或弹提示；
  由闸门确认资源管理器**真的发生了导航**（目录变了）之后，才播放音效并弹出手势图标。
  如果后退/前进已到顶（没有历史），本次手势**不发声、不提示**，避免"明明没动却响一声"的困惑。
- **识别后的余动抑制（220ms）**：一次完整手势识别后，短时间内屏蔽新的识别并清空轨迹，
  丢弃画圈尾段、手抖等余动，避免一次动作被反复识别成多个手势（表现为"画完停着却连续触发"）。
- **离开列表区的宽限期（800ms）**：切换窗口、目录加载时区域判定会瞬时断开，宽限期内不重置轨迹，
  避免正在进行的手势被打断；超过宽限期才真正重置。
- **异常兜底**：界面线程与未处理异常会写入 `%LOCALAPPDATA%\Glix\error.log`，
  托盘程序不再无痕消失。

## 构建与运行

```powershell
cd Glix
dotnet build
.\bin\Debug\net10.0-windows\Glix.exe
```

程序以后台托盘图标形式运行（单实例，重复启动会直接退出）。

托盘菜单：

- 暂停手势
- 提示音（默认开）：总开关，关闭后完全静音
- 使用系统导航音效（默认勾选）：勾选时由 Windows 系统自身在导航时发声，程序不再重复播放；若系统未配置导航音会提示打开声音设置。取消勾选则改用程序内置自定义音效，并把系统「导航」声音在注册表中设为无声以避免双响
- 动作提示（默认关）：开启后，导航成功时在窗口右下角弹出手势图标
- 退出

## 调参

手势阈值在 `GestureOptions.cs`：

| 项 | 默认 | 说明 |
|---|---|---|
| `MinTurnDegrees` | 270 | 累计转角阈值，调小更易触发 |
| `MinPathLengthPx` | 120 | 轨迹总长度下限 |
| `MinSpanPx` | 60 | **直径下限**，小于此值不触发 |
| `MaxSpanPx` | 420 | **直径上限**，大于此值不触发 |
| `MinAspectRatio` | 0.45 | 扁度下限，排除横向来回等扁长轨迹 |
| `MaxRadiusVariation` | 0.35 | 半径起伏上限，排除折线、S 形等非圆轨迹 |
| `IdleResetMs` | 260 | 静止多久重置；画得慢可调大 |
| `OffListGraceMs` | 800 | 离开列表区的宽限期；切换窗口后手势被打断可调大 |
| `GestureSuppressionMs` | 220 | 识别后屏蔽余动的时长；若仍有"画完连续触发"可调大 |
| `MaxGestureDurationMs` | 2200 | 单个手势最长时间 |

闸门冷却在 `NavigationGateOptions.cs`：`CooldownMs` 350。两次导航的最短间隔，低于此值的新手势会被直接丢弃。

音效在 `SoundFeedback.cs` 的默认构造中调整（频率、时长、幅度见 `ToneOptions.cs`）。

## 已在本机实测的项

- 资源管理器窗口层次：`DirectUIHWND -> SHELLDLL_DefView -> CtrlNotifySink -> DirectUIHWND -> DUIViewWndClassName -> ShellTabWindowClass -> CabinetWClass`；列表区判定命中，导航窗格与标题栏不命中。
- 形状区分（合成鼠标事件，四项全部符合预期）：

  | 轨迹 | 期望 | 实测 | 关键指标 |
  |---|---|---|---|
  | 横向来回 ±110px × 5 趟 | 不触发 | 不触发 | 扁度 0.08、起伏 0.55 |
  | 小圈 半径 30 | — | 触发（直径 60 已达下限） | 直径 60 |
  | 大圈 半径 244 | 不触发 | 不触发 | 直径 488 > 420 |
  | 正常圈 半径 70 | 触发 | 触发 | 直径 140、转角 270° |

- 连续两个圈（不停顿）：后退 2 次，提示窗正常弹出；连续 3 个紧凑圈在闸门开启时后退 2 次、闸门关闭时后退 5 次。
- 到顶不反馈：导航到历史起点后画圈，提示窗**不出现**、目录不变（即不发声、不提示）。
- 切换场景回归：直接画圈、切换目录后画圈（子窗口重建）、切到别的窗口再切回后画圈，三项均触发。
- 提示窗：56 × 56 像素，不透明度 183/255（0.72），位于目标窗口右下角，约 1.9 秒后自动隐藏。
